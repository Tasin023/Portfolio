I learned by building complete things: mobile apps, desktop tools, web experiments, backend services, and interfaces that had to work outside a tutorial.

That process taught me to move between the visible layer and the machinery underneath it. I care about the small details users feel, but I also care about the data, APIs, storage, and decisions that make those details reliable.
